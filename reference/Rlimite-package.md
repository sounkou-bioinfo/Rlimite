# Rlimite: native torch inference for Limite language models

Implements the Limite mathematical language-model architecture
<https://github.com/paradigma-inc/limite-violetto> directly with
'torch'. Loads the published Base, Base Soup, and Violetto 'safetensors'
checkpoints and tokenizers from the 'Hugging Face' Hub without a Python
runtime or model-serving process. Provides cached autoregressive
generation and the official single-turn prompt format used by the
math-specialized Violetto checkpoint.
